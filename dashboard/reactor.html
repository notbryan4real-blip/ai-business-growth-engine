Board model
Checking configuration…
The default board is Opus 5.5; workers use the existing lower-cost model. A configured key is not proof of available credit. Model failures block new entries for that cycle and keep the rules report. Your other Swarm workflows retain their existing model.
What this system measures
Source freshness, strategy scores, paper fills, trading costs, drawdown, and actual run latency. Scores are unvalidated rules, not probability estimates.
This system does not claim 128-module verification in 0.12 seconds, hundreds of thousands of guards, or guaranteed profits. Standard tests and deployment checks remain in place.
