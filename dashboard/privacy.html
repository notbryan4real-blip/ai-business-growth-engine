Privacy Policy

Last updated: October 17, 2026

Production setup required: The operator must add a valid privacy-request contact channel and review this policy before enabling public production use of Google Places data or accepting external users.

Information processed

The application may process business prospect information entered by the user, notes and observations, generated drafts, task and agent outputs, and manually entered sales or revenue records. Do not enter passwords, payment-card details, or sensitive personal information into prospect notes or AI prompts.

Browser storage

The dashboard stores its workspace in the browser's local storage and can export a JSON backup. This information remains in that browser until it is cleared or the user removes it. Anyone with access to the unlocked browser profile may be able to view it.

Server storage

The API stores prospect records and AI run outputs in its configured data store. The current MVP may use a local JSON file on the hosting instance; availability and retention are not guaranteed across hosting restarts. The operator should configure durable storage and a retention process before relying on the service for business-critical information.

Google Maps Platform

Google Places search results are displayed temporarily with Google Maps attribution. The application retains only Google Places place IDs for repeat-search tracking; it does not intentionally persist returned names, addresses, phone numbers, ratings, or website URLs. Use of Google Maps Platform is subject to the Google Privacy Policy, Google Maps Platform Terms of Service, and Places API policies.

AI and other providers

If AI features are configured, the selected AI provider receives the request content required to generate a response. Review that provider's privacy terms and avoid submitting information that is not necessary. Other connected services may process data according to their own privacy policies.

Sharing and security

The application does not intentionally sell user-entered prospect records. Data may be processed by configured hosting and service providers to operate requested features. Secrets should be kept in server-side environment variables, never in public source files or browser code. No internet-connected application can guarantee absolute security.

Retention and requests

Browser records persist until cleared or overwritten. Server-side records persist according to the configured storage and retention process. Contact the operator to request access, correction, or deletion where applicable.

Operator contact

Operator contact details have not yet been configured. This section must be completed before public production use.
